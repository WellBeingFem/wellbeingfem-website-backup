# GitHub migration boundary

This private repository is intentionally source-plus-public-assets only.

Allowed here:

- production source, routes, page content, policy text, form code, schema definitions, migrations, public images/PDFs, crawler/SEO configuration, build files, and migration documentation;
- public, non-sensitive original uploaded asset files.

Do not add here:

- Resource Request submissions;
- names, email addresses, consent records, consent timestamps, or other client data;
- database dumps containing production rows;
- contact-enquiry data;
- passwords, API keys, database connection strings, private tokens, OAuth credentials, or DNS credentials.

Use the separately protected migration package and a destination secret manager for those materials.
